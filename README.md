# Memonizer

Десктопное приложение на Kotlin для автоматической организации фотографий и видео по датам съёмки.

## Описание

Memonizer — это утилита с графическим интерфейсом, которая помогает упорядочить медиафайлы, извлекая из них метаданные (EXIF) и группируя по датам. Приложение построено на Jetpack Compose Desktop и использует библиотеку `metadata-extractor` для чтения информации о дате съёмки из изображений и видео.

## Возможности

- Выбор исходной и целевой директории через GUI
- Автоматическое сканирование и подсчёт медиафайлов (изображений и видео)
- Извлечение даты съёмки из EXIF-метаданных
- Организация файлов по датам в формате `yyyy-MM-dd`
- Отслеживание прогресса обработки
- Компактный интерфейс (600×210 пикселей)

## Технологии

- **Kotlin Multiplatform** (JVM target)
- **Jetpack Compose Desktop** — современный декларативный UI
- **metadata-extractor 2.18.0** — извлечение EXIF-данных
- **Gradle (Kotlin DSL)** — сборка проекта

## Структура проекта

```
src/jvmMain/kotlin/
├── Main.kt              # Точка входа приложения
├── AppState.kt          # Состояние приложения
├── blocks/              # UI-блоки (выбор папок, подготовка, запуск)
├── constants/           # Константы
├── extensions/          # Расширения Kotlin
├── extractor/           # Модуль извлечения метаданных
└── service/             # Сервисы (FileService, MetadataService)
```

## Требования

- JDK 11 или выше

## Сборка и запуск

```bash
# Запуск приложения
./gradlew run

# Сборка нативных дистрибутивов
./gradlew packageDmg        # macOS
./gradlew packageMsi        # Windows
./gradlew packageDeb        # Linux
```

## Использование

1. Запустите приложение
2. Выберите исходную папку с медиафайлами
3. Выберите целевую папку для организованных файлов
4. Нажмите "Подготовить" для сканирования
5. Нажмите "Запустить" для начала обработки
